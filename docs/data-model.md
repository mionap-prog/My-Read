# Data model

The data the app saves.

## Item: Book

| Field      | Type                                     | Notes                    |
| ---------- | ---------------------------------------- | ------------------------ |
| `id`       | unique identifier                        | generated by the app     |
| `title`    | text                                     | **required**             |
| `author`   | text                                     |                          |
| `source`   | one of `Owned` / `Borrowed` / `Library`  | where the book comes from |
| `language` | text                                     |                          |
| `status`   | one of `Want to read` / `Reading` / `Read` |                        |
| `notes`    | longer text                              |                          |
| `addedAt`  | date                                     | the date the book was added |
